# Prof. Samuel Chisa Dike & Co.

A professional legal website for Omuordu Chambers in Port Harcourt, Nigeria. This single-page site presents the firm’s practice areas, principal profile, credentials, and contact details in a polished, responsive format.

## Overview

This project is built with HTML, CSS, and JavaScript and is designed to project professionalism, integrity, and legal expertise. It includes a premium dark/light theme, mobile-friendly navigation, animated hero section, and a contact form.

## Features

- Responsive single-page layout
- Elegant legal branding and typography
- Dark and light theme toggle
- Practice areas and firm profile sections
- Contact form and call-to-action buttons
- Optimized for Firebase Hosting

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Firebase Hosting

## Local Preview

Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This project is set up for Firebase Hosting.

```bash
firebase login
firebase deploy
```
